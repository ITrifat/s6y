# Rifat Hasan — AI Agent Workflow Architect

A zero-cost, static personal portfolio website designed for GitHub Pages, Netlify, Cloudflare Pages or Vercel.

## Before publishing
Open `index.html` and replace:
- `YOUR-EMAIL@example.com` with your real email
- `https://www.linkedin.com/` with your real LinkedIn profile URL
- Starter/portfolio-concept projects with your real projects as you build them

## Free deployment options
### GitHub Pages
1. Create a GitHub account.
2. Create a public repository, e.g. `rifat-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`.
4. Repository → Settings → Pages → Deploy from branch → `main` / root.
5. GitHub will give you a public URL.

### Netlify / Cloudflare Pages / Vercel
Upload/connect the same three files. The site is static and requires no paid server or database.

## Editing projects
In `index.html`, duplicate a `.project-card`, change its title, category, description and art, then add a real case study. The existing modal is ready for expansion.
